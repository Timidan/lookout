Controls

TapTake the action shown, or send a priced order
HoldConfirm a big action (2 s), so a brushed temple never closes a position. Elsewhere, hold to speak a command such as "Long BTC" (needs a speech-to-text endpoint; the hosted app has none yet)
Double tapBack
SwipeNext card, or change a ticket's size

Install

  1. On your G2

    Turn on developer mode in the Even app, then scan the code this prints: 
    npm install -g @evenrealities/evenhub-cli
evenhub qr --url https://lookout.timidan.xyz/app

    Built and tested in the simulator; not yet run on hardware.

  2. Pair your wallet

    The glasses show a six-letter code and a link. On your phone, your wallet signs one Hyperliquid testnet agent approval, valid for seven days. Before pairing, Lookout runs on a read-only sample account.

  1. Or try it in the simulator

    npm install -g @evenrealities/evenhub-simulator
evenhub-simulator https://lookout.timidan.xyz/app

  2. Package

    lookout-0.1.0.ehpk (57 KB), the Even Hub package, built against this server. Also on GitHub Releases.

Testnet only

  • The approval names Hyperliquid testnet, so it cannot authorise a mainnet agent.
  • The agent key can trade but cannot withdraw. It stays encrypted on the server; the glasses hold only a session token.
  • New orders are capped at $200. Every new long or short carries a stop.
  • Lookout shows your own positions and acts only when you tap or hold. It gives no financial advice.
